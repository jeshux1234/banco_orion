# Banco Orion

Sistema bancario básico desarrollado en Python para practicar conceptos de programación orientada a objetos, gestión de clientes, cuentas y operaciones financieras.

## Descripción

El proyecto simula un banco con las siguientes funcionalidades:

- Registro de clientes
- Creación y manejo de cuentas bancarias
- Depósitos, retiros y transferencias
- Consulta de historial de movimientos
- Reporte general del sistema
- Menú interactivo para usuarios

## Estructura del proyecto

```text
banco_orion/
├── sistema_bancario/
│   ├── admin.py
│   ├── gestor_de_clientes.py
│   ├── historial.py
│   ├── menu_principal.py
│   ├── operaciones_bancarias.py
│   ├── pruebas.py
│   └── sistema.py
└── README.md
```

## Cómo ejecutar

Desde la carpeta raíz del proyecto, ejecuta:

```bash
python sistema_bancario/menu_principal.py
```

## Requisitos

- Python 3.x
- Consola o terminal para interactuar con el menú

## Fases del proyecto

El repositorio está organizado por ramas para cada etapa:

- `main`: documentación principal
- `fase-1-base`: base del sistema
- `fase-2-gestion-clientes`: registro y gestión de clientes
- `fase-3-operaciones-bancarias`: depósitos, retiros y transferencias
- `fase-4-administracion`: administración del sistema
- `fase-5-pruebas`: validación y pruebas

## Nota

Este proyecto es una aplicación de ejemplo educativa y puede ampliarse con nuevos módulos, validaciones y mejores prácticas de desarrollo.
